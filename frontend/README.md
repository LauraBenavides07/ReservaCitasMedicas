# Piedrazul - Frontend

Este es el frontend del sistema de gestión de citas médicas **Piedrazul**, construido como una SPA con **Angular** (versión 21+).
El diseño tiene un enfoque **Mobile-First** y prioriza fuertemente la **Accesibilidad** (adultos mayores, WCAG AAA).

## Instalación

> **Importante**: Este proyecto utiliza `pnpm`. No utilices `npm`.

```bash
# Instalar dependencias
pnpm install
```

## Levantar el proyecto

Para iniciar el servidor de desarrollo:

```bash
pnpm start
```
La aplicación estará disponible en `http://localhost:4200/`.

## Pruebas

Para ejecutar las pruebas unitarias con **Vitest**:

```bash
pnpm exec vitest run
```

> Para más detalles sobre la arquitectura y backend, por favor consulta el `README.md` principal en la raíz del proyecto.
